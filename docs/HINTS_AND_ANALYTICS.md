# Эксперимент: подсказки, реклама и измерение интереса

## Игровая экономика тестовой версии

Игрок начинает с 8 открытий произвольной буквы, 4 открытий первой буквы,
4 открытий случайной гласной, 3 дополнительных попыток, 4 удалений лишних
букв и 4 дополнительных подсказок о слове (число гласных).

Открытие буквы: выбрать клетку в верхнем слове. В одном раунде можно открыть
не более трёх букв, причём одна всегда остаётся неизвестной. Дополнительная
попытка разрешена одна за раунд и увеличивает лимит с четырёх до пяти.
Удаление лишних клавиш и дополнительное описание — по одному за раунд.

Каждые 3 победы: +2 открытия букв и одна другая подсказка по кругу.
Первое прохождение уровня: +3 открытия букв и по одному каждого другого вида.

На Яндекс Играх пользователь может добровольно посмотреть бонусную рекламу
и выбрать запас, который восстановится. Награда начисляется только после
события SDK `onRewarded`, не по `onClose` и не по факту нажатия на кнопку.
На GitHub Pages кнопка рекламной награды недоступна.

Списанные подсказки, текущий раунд и бонусная попытка сохраняются.
Для авторизованных игроков добавлены поля облачного сохранения подсказок.
**До публикации необходимо проверить сценарии игры с двух устройств:** текущее
объединение балансов через максимум не является точным учётом параллельных
списаний на разных устройствах.

## Словарь

Существующий банк 1000 заданий не меняется. Если русское слово подходящей
длины не оказалось в текущем словаре, игрок видит предупреждение и может
нажать «Проверить» повторно, осознанно потратив попытку. Так мы избегаем
необоснованной блокировки реальных слов и сохраняем возможность ограничивать
случайные нажатия. Отдельно нужно проверить доступные лицензии и размер
расширенного словаря глаголов, прилагательных и распространённых словоформ.

## Аналитика

Встроенные метрики Яндекс Игр после публикации: уникальные игроки,
новые игроки, конверсия в игру (>60 секунд), игровые минуты, удержание D1/D3/D7,
показы rewarded/interstitial на игрока, рекламный доход. Большинство
метрик обновляются с задержкой 2–3 дня, поэтому не делайте выводы по
первым часам и тестовому черновику.

Файл `analytics.js` содержит только безопасные события:
`game_start`, `round_win`, `round_loss`, `hint_used`,
`reward_ad_open`, `reward_ad_rewarded`, `reward_ad_error`,
`dictionary_miss`.

Чтобы видеть воронку конкретных игровых событий, создайте отдельный
счётчик Яндекс Метрики, добавьте его код через настройки Метрики,
установите `window.GAME_METRIKA_ID = <ID>` перед `analytics.js` и
зарегистрируйте цели с идентификаторами событий выше. Не передавайте в
события ники, данные аккаунта и текст слов. Пока счётчик не создан и ID
не указан, события не отправляются — работают только встроенные метрики
Яндекс Игр.
