## Проверки

Все команды завершились успешно:

```sh
node tests/check-release.cjs
node tests/check-community.cjs
node tests/check-audit.cjs
```

Новый тест выполняет игровые функции в Node с моделью DOM: все 1000 слов, 50 уровней, 50 частей, 10 печатей; повтор уровня; восстановление подсказок и дополнительной попытки; отсутствие повторного списания; отклонение неизвестного слова; повреждённые сохранения; обновление ника; однократный Game Ready; наложение рекламной и платформенной пауз; возвращение в меню; выбор актуального облачного баланса. Это не визуальный браузерный тест и не реальный показ рекламы.

Банк содержит 1000 уникальных заданий, по 20 на каждый уровень. Пустые подсказки и повторяющиеся задания текущие проверки не обнаружили. Рейтинг использует серверные RPC и показывает состояние недоступности; имитации общего рейтинга в клиентском коде нет. Миграции базы в ходе этой проверки не менялись.

Новый тест подключён к GitHub Actions. Версии изменённых ресурсов подняты до v50.

## Сверка с Яндекс Играми

Официальные требования просмотрены 2 октября 2026; на странице указана дата изменения 29 сентября 2026.

- [Требования](https://yandex.ru/dev/games/doc/ru/concepts/requirements): сохранение прогресса, потеря фокуса, адаптация, пауза при рекламе, явная рекламная награда.
- [Подключение SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about): относительный `/sdk.js` для архива на Яндексе, инициализация после загрузки.
- [Game Ready и Gameplay API](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events): готовность интерфейса, старт/остановка активного раунда.
- [Реклама](https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv): логические паузы, обработка отказа, награда только по `onRewarded`.
- [События](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events): автоматическая стартовая реклама и события паузы/возобновления.
- [Данные игрока](https://yandex.ru/dev/games/doc/ru/sdk/sdk-player): `isAuthorized`, добровольный вход, `getData` / `setData`.

## Что требует реальной проверки или отдельной доработки

1. Запустить архив в черновике Яндекса с debug-панелью. Проверить Game Ready, Gameplay API, автоматическую стартовую рекламу, interstitial после трёх раундов, отказ в показе и rewarded с выдачей/без выдачи бонуса.
2. Проверить Android: портрет, горизонталь, длинные выражения, системную клавиатуру, открытые подсказки, поворот и возврат из рекламы. В CSS остаются режимы, которые могут требовать прокрутки на коротком экране. Требования 1.10.2 и 1.10.4 нельзя считать подтверждёнными без визуального прогона; основные элементы игры должны быть видны сразу.
3. В черновике проверить платформы, ориентацию, русский язык, монетизацию и флаг облачных сохранений. Содержимое черновика в этой проверке недоступно.
4. Общий рейтинг привязан к анонимной сессии этого браузера, а не Яндекс ID. На другом устройстве возможен отдельный профиль рейтинга. Проверена логика клиента, но реальная запись/чтение сервера в этой проверке не выполнялись.
5. Облачное объединение счётчиков статистики берёт максимум, а баланс подсказок — более свежий снимок. Это не полноценное объединение одновременной игры на двух устройствах; часть параллельных операций может потеряться.
6. Архив нельзя считать прошедшим модерацию только на основании этих тестов. Браузер для локального визуального прогона скачать в текущей среде не удалось.
