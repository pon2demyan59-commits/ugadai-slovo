# Угадай слово

Простая мобильная браузерная игра.

## Что уже есть

- случайное слово из списка;
- 1000 заданий: первый уровень в `data/words.js`, остальные — в `data/levels/`;
- подсказка;
- 4 попытки угадать слово и последний шанс вписать недостающие буквы;
- зеленые буквы, если буква стоит на правильном месте;
- белые буквы, если буква есть в слове, но стоит в другом месте;
- пустые клетки, если такой буквы в слове нет;
- счетчик текущей попытки и оставшихся попыток;
- экранное сообщение о победе или поражении;
- переход к следующему слову и сохранение незаконченного раунда;
- базовая PWA-обертка для установки на телефон.

## Как запустить

Открой файл `index.html` в браузере.


## Яндекс Игры — техническая подготовка

- `yandex-platform.js` загружает `/sdk.js` только в окружении Яндекса. GitHub Pages работает без SDK.
- После готовности интерфейса вызывается Game Ready; начало и окончание раунда, меню и переключение вкладок размечены через Gameplay API.
- Полноэкранная реклама запрашивается только после клика «Следующее слово» или «К уровням»: не раньше четырёх завершённых раундов и трёх минут с предыдущего запроса.
- Локальный прогресс сохраняется. Для авторизованных игроков добавлена облачная синхронизация через Player API; гости продолжают сохранять прогресс локально. Проверить её на реальном SDK необходимо до публикации.
- На Яндексе Service Worker не регистрируется, на GitHub Pages HTML проверяется в сети при каждом переходе.


## Облачные сохранения

- `game-bootstrap.js` сначала восстанавливает облачные данные авторизованного игрока, затем запускает `script.js`.
- При входе через Яндекс ID по кнопке «Сохранить в облаке» страница перезагружается для безопасного слияния данных до загрузки игры.
- Разгаданные слова объединяются по множествам, чтобы не терять достижения с разных устройств; счётчики статистики берут максимум по каждому показателю и могут не полностью учитывать параллельную игру на нескольких устройствах.
- При недоступности SDK, ошибке сети или гостевом входе всегда остаётся локальное сохранение. Облачная отправка выполняется с задержкой во время ввода и немедленно при завершении раунда.


## Сборка для Яндекс Игр

При изменениях в ветке `feature/yandex-release` GitHub Actions проверяет банк из 1000 заданий, наличие ресурсов и синтаксис JavaScript, а затем создаёт `ugadai-slovo-yandex.zip` в артефактах workflow «Yandex Games release checks». Для тестирования откройте архив в черновике игры. В нём `index.html` расположен в корне. Проверку SDK, рекламы и облачных сохранений нужно завершить в консоли Яндекса перед модерацией.

## Фирменная пасхалка «Бинарный импульс»

Игрок может сохранить ник (2–24 символа, буквы, цифры, пробел, дефис или подчёркивание). За прохождение всех пяти уровней каждой из 10 категорий открывается один фрагмент пазла. Прогресс пазла вычисляется из уже разгаданных слов и доступен старым игрокам без повторного прохождения. После 10/10 открывается именная грамота компании «Бинарный импульс» со статистикой, датой выдачи и кнопкой печати/сохранения через диалог браузера в PDF. Статистика раундов не обязана равняться 1000, поскольку поражения и повторные попытки тоже учитываются. Ник и дата выдачи синхронизируются через облачное сохранение для авторизованных игроков Яндекса; работа без SDK остаётся локальной.
