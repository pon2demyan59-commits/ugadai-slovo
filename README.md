# Угадай слово

Простая мобильная браузерная игра.

## Что уже есть

- случайное слово из списка;
- 1000 заданий: первый уровень в `data/words.js`, остальные — в `data/levels/`;
- подсказка;
- 4 попытки угадать слово и последний шанс вписать недостающие буквы;
- зеленые буквы, если буква стоит на правильном месте;
- белые буквы, если буква есть в слове, но стоит в другом месте;
- пустые клетки, если такой буквы в слове нет;
- счетчик текущей попытки и оставшихся попыток;
- экранное сообщение о победе или поражении;
- переход к следующему слову и сохранение незаконченного раунда;
- манифест для установки; Service Worker отключён после смены оформления.

## Как запустить

Запусти `python3 -m http.server 8000` в папке игры и открой `http://localhost:8000`. Расширенный словарь загружается через fetch и требует HTTP.


## Яндекс Игры — техническая подготовка

- `yandex-platform.js` загружает `/sdk.js` только в окружении Яндекса. GitHub Pages работает без SDK.
- После готовности интерфейса вызывается Game Ready; начало и окончание раунда, меню и переключение вкладок размечены через Gameplay API.
- Полноэкранная реклама запрашивается только после клика «Следующее слово» или «К уровням»: после трёх завершённых раундов и не раньше трёх минут с предыдущего успешного показа. При отказе повторный запрос возможен на следующем переходе через минуту.
- Локальный прогресс сохраняется. Для авторизованных игроков добавлена облачная синхронизация через Player API; гости продолжают сохранять прогресс локально. Проверить её на реальном SDK необходимо до публикации.
- На Яндексе Service Worker не регистрируется, на GitHub Pages HTML проверяется в сети при каждом переходе.


## Облачные сохранения

- `game-bootstrap.js` сначала восстанавливает облачные данные авторизованного игрока, затем запускает `script.js`.
- При входе через Яндекс ID по кнопке «Сохранить в облаке» страница перезагружается для безопасного слияния данных до загрузки игры.
- Разгаданные слова объединяются по множествам, чтобы не терять достижения с разных устройств; счётчики статистики берут максимум по каждому показателю и могут не полностью учитывать параллельную игру на нескольких устройствах.
- При недоступности SDK, ошибке сети или гостевом входе всегда остаётся локальное сохранение. Облачная отправка выполняется с задержкой во время ввода и немедленно при завершении раунда.


## Сборка для Яндекс Игр

При изменениях в `main`, `feature/**` или `fix/**` GitHub Actions проверяет банк из 1000 заданий, наличие ресурсов и синтаксис JavaScript, а затем создаёт `ugadai-slovo-yandex.zip` в артефактах workflow «Yandex Games release checks». Для тестирования откройте архив в черновике игры. В нём `index.html` расположен в корне. Проверку SDK, рекламы и облачных сохранений нужно завершить в консоли Яндекса перед модерацией.

## Фирменная пасхалка «Бинарный импульс»

Игрок может сохранить ник (2–24 символа, буквы, цифры, пробел, дефис или подчёркивание). Каждый пройденный уровень открывает фрагмент печати. Пять фрагментов раскрывают одну печать категории; всего 50 фрагментов и 10 печатей. Прогресс пазла вычисляется из уже разгаданных слов и доступен старым игрокам без повторного прохождения. После раскрытия 10/10 печатей открывается именная грамота компании «Бинарный импульс» со статистикой, датой выдачи и кнопкой печати/сохранения через диалог браузера в PDF. Статистика раундов не обязана равняться 1000, поскольку поражения и повторные попытки тоже учитываются. Ник и дата выдачи синхронизируются через облачное сохранение для авторизованных игроков Яндекса; работа без SDK остаётся локальной.

## ВКонтакте — приложение 54837354

- `vk-platform.js` выбирает VK при наличии параметров запуска `vk_app_id=54837354` и `vk_user_id`. Обычный запуск и Яндекс сохраняют прежнюю интеграцию.
- Официальный VK Bridge **3.0.2** включён локально в `vendor/vk-bridge/` вместе с лицензией MIT. Источник: npm-пакет `@vkontakte/vk-bridge@3.0.2`, официальный проект https://github.com/VKCOM/vk-bridge.
- После `VKWebAppInit` проверяется совпадение пользователя через `VKWebAppGetUserInfo`. Токен доступа и отдельный вход в игре не нужны. Параметры URL используются для разделения локального кэша, а не для серверной авторизации. Нельзя использовать такую проверку для платежей или прав доступа на сервере.
- Прогресс читается до запуска игры через `VKWebAppStorageGet`. Сохраняются разгаданные слова, уровни, незаконченные раунды, статистика, ник, дата грамоты и баланс подсказок. Локальные данные разделены по ID приложения и пользователя; данные гостя и Яндекса автоматически не импортируются.
- Отправка выполняется после паузы во вводе и при завершении раунда, сворачивании или нажатии кнопки сохранения. Статус сохранения виден в меню. Ошибка чтения запрещает запись в облако в этой сессии; кнопка повторной синхронизации перезапускает игру с локальной копией.
- Снимок делится на ASCII-части по 3000 байт. Два слота и контрольная сумма защищают от неполной записи; метаданные переключаются после успешной записи частей. Неизменившиеся части повторно не отправляются. Слишком большой снимок отклоняется без замены активного сохранения.
- Обнаруженное изменение облака с другого устройства не перезаписывается: требуется перезапуск для слияния. Полная транзакционная синхронизация одновременной игры на нескольких устройствах не гарантируется: Storage не предоставляет compare-and-swap. Для обычного последовательного перехода между устройствами прогресс восстанавливается и объединяется существующим механизмом.
- Обработаны события `VKWebAppViewHide`/`VKWebAppViewRestore`: пауза звука, блокировка ввода в скрытом приложении и отправка прогресса.
- Реклама VK пока **не подключена**, блок рекламных бонусов в VK скрыт. Поддержка рекламы Яндекса сохранена. Общий рейтинг остаётся прежним отдельным сервисом с анонимной сессией; это не хранилище прогресса аккаунта VK.

### Проверка перед публикацией

1. После успешного GitHub Pages deployment указать адрес игры в разделе «Размещение» для поддерживаемых платформ. Состояние оставить «Отключено» для административного теста.
2. Запустить **из VK**, проверить меню, ввод букв, завершение раунда и статус «Прогресс сохранён в VK».
3. Открыть игру на втором устройстве с тем же VK-аккаунтом: проверить ник, слова, уровни, подсказки и незавершённый раунд.
4. Проверить другой VK-аккаунт в том же браузере: он не должен получить чужую локальную копию. Проверить восстановление после ошибки сети и паузу при сворачивании.
5. Запуск в настоящем VK, права Storage и работа на Android/iOS/Web требуют ручного теста. Автоматические тесты используют имитацию Bridge и не заменяют проверку внутри платформы.
