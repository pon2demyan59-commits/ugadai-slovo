# Угадай слово

Простая мобильная браузерная игра.

## Что уже есть

- случайное слово из списка;
- база из 110 слов с подсказками в `data/words.js`;
- подсказка;
- 4 попытки угадать слово целиком;
- зеленые буквы, если буква стоит на правильном месте;
- белые буквы, если буква есть в слове, но стоит в другом месте;
- пустые клетки, если такой буквы в слове нет;
- счетчик текущей попытки и оставшихся попыток;
- статистика угаданных и неугаданных слов;
- прогресс слов в `localStorage`;
- финальная попытка вписать недостающие буквы;
- кнопка подсказки через rewarded-рекламу Яндекс Игр;
- экран победы или поражения;
- базовая PWA-обертка для установки на телефон.
- мягкая интеграция SDK Яндекс Игр через `yandex-sdk.js`.

## Как запустить

Открой файл `index.html` в браузере.

Для публикации на Яндекс Играх нужен архив с `index.html` в корне.
